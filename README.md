# Book-Fair-Reservation-System Backend

This repository contains the **backend** code for the Book Fair Reservation System, a project developed for the final year group project at the Faculty of Engineering, University of Ruhuna.

## Features

* User registration and login
* Role-based access control (Admin, Organizer, Visitor)
* Book fair reservation management
* RESTful API endpoints
* Database integration with [your DB choice]

## Tech Stack

* Java Spring Boot
* Spring Security
* JPA/Hibernate
* MySQL (or PostgreSQL)
* Maven

## Getting Started

### Prerequisites

* Java 17+
* Maven
* MySQL / PostgreSQL
* Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Final-Year-Group-Projects-FOE-UOR/Book-Fair-Reservation-System---Backend.git
   ```
2. Navigate into the project:

   ```bash
   cd Book-Fair-Reservation-System---Backend
   ```
3. Open in your IDE (IntelliJ IDEA, Eclipse, VS Code)
4. Configure your database in `application.properties`
5. Run the project:

   ```bash
   mvn spring-boot:run
   ```
